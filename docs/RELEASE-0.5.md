# v0.5 public alpha

A separate continuation of Cardinal 3D for live modular music in shared 3D spaces. The earlier v0.77 remains separately available.

Includes an embedded Windows desktop/Quest performer, full hardware audio input/output controls, MIDI, multiple cases/environments, spatial speaker and CV/clock-driven visual modules, chat boards, visitors/avatars/reactions, mobile/WebXR controls, persistent welcome hosting and optional Telegram announcements.

Desktop improvements include a compact wrapping toolbar and arrow navigation. Visitor improvements include touch movement, movable VR chat/sound HUD, keyboard, compressed decoder fallback, scene deltas and mobile jitter handling.

Native engine/full-library, input routing, spatial monitoring and frontend checks run locally. Browser tests exercise actual audio decoding, a real relay, permission limits, deltas, jitter recovery, HUD interactions and offline homepage persistence. Physical-device acceptance remains ongoing. Windows x64/USB Quest 2 are primary performer targets. Binaries are unsigned; sustained 100-listener certification, SFU/TURN and broad device testing remain future work.

The Windows ZIP is paired with complete matching sources and checksums. Recursive Cardinal sources, bindings, GPL ASIO SDK and dependency sources accompany this project. Browser decoder sources are pinned to the npm package's recorded revision. Keep corresponding sources available with redistributed binaries. GitHub's automatic source ZIP is incomplete.

Required author/licence notices are retained. Private credentials, machine configuration, saved patches, profile information and performance history are excluded from public artifacts.
